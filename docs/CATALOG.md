## 1. Генерация изображений

### 1.1 Загрузка изображений
- **Drag & Drop** интерфейс для загрузки файлов
- Поддержка форматов: **JPG, PNG, WebP**
- Максимальный размер файла: **10MB**
- Мультизагрузка (несколько референсов одновременно)
- Предпросмотр загруженных изображений с возможностью удаления

### 1.2 Выбор пресета
- Выпадающий список с миниатюрами пресетов
- Быстрый поиск по названию пресета
- Предпросмотр параметров выбранного пресета
- Автозаполнение промта из пресета

### 1.3 Написание промта
- Многострочное текстовое поле с автодополнением
- Подсветка синтаксиса для ключевых слов
- Шаблоны популярных стилей
- Рекомендации по улучшению промта

### 1.4 Негативный промт
- Поле для указания нежелательных элементов
- Предустановленные шаблоны (размыто, низкокачественное, etc.)
- Валидация на противоречия с основным промтом

### 1.5 Настройки генерации
| Параметр | Диапазон | Рекомендуемое значение |
|----------|----------|------------------------|
| Разрешение | 512x512 - 2048x2048 | 1024x1024 |
| Качество (CFG Scale) | 1-10 | 7-8 |
| Steps | 10-150 | 30-50 |
| Seed | -1 (random) или конкретное число | -1 |

### 1.6 Статусы генерации
```
queued → processing → completed / failed
```
- **Real-time обновление** статуса через SSE/WebSocket
- Индикатор прогресса с детализацией этапов
- Уведомления о завершении/ошибках

### 1.7 Редактирование результатов
- Клик по изображению открывает модальное окно редактора
- Изменение промта для существующего изображения
- Генерация новой версии с сохранением оригинала
- История версий с возможностью отката

### 1.8 Сохранение в Bitrix24
- Загрузка в **Bitrix Disk** через API
- Привязка к сущностям: Сделки, Контакты, Компании, Смарт-процессы
- Поддержка одиночных и множественных файловых полей
- Автоматическое создание UF_* полей при необходимости

## 2. Управление пресетами

### 2.1 Создание пресета
- Название и описание
- Базовый промт (template с переменными)
- Системный промт для модели
- Референсное изображение (миниатюра)
- Параметры модели: разрешение, качество, steps

### 2.2 Пресет из изображения (AI-анализ)
- Загрузка референсного изображения
- **Image-to-Prompt** анализ через Vision-модель
- Автоматическая генерация детального промта
- Распознавание стиля, цветов, композиции

### 2.3 Редактирование пресета
- Изменение всех параметров существующего пресета
- Предпросмотр изменений перед сохранением
- Версионирование (история изменений)

### 2.4 Удаление пресета
- Валидация: нельзя удалить используемый в активных задачах
- Подтверждение удаления
- Архивирование вместо полного удаления (опционально)

### 2.5 Экспорт/Импорт пресетов
- **JSON формат** для обмена
- Пакетный экспорт всех пресетов
- Импорт с валидацией структуры
- Библиотека готовых пресетов

## 3. Интеграция с Bitrix24

### 3.1 OAuth2 авторизация
- Регистрация приложения как **Local App** в Bitrix24
- Мастер установки с пошаговой настройкой
- Автоматический refresh токенов
- Безопасное хранение credentials (шифрование AES-256-GCM)

### 3.2 Маппинг полей
| Тип поля Bitrix24 | Описание | Поддержка |
|-------------------|----------|-----------|
| FILE | Одиночный файл | ✅ |
| MULTIPLE_FILE | Несколько файлов | ✅ |
| STRING | Текстовое поле | ✅ |
| JSON | Структурированные данные | ✅ |

### 3.3 Сущности CRM
- **Сделки** (crm.deal)
- **Контакты** (crm.contact)
- **Компании** (crm.company)
- **Смарт-процессы** (crm.*.smartprocess.*)

### 3.4 Вебхуки для синхронизации
- Подписка на события: `onCrmEntityUpdate`, `onCrmEntityAdd`
- Двусторонняя синхронизация данных
- Обработчики изменений в реальном времени

### 3.5 Работа с Disk API
- `disk.file.add` - загрузка файлов
- `disk.folder.get` - получение папок
- `disk.file.upload` - прямая загрузка
- Конвертация локальных URL в FILE_ID

## 5. Мониторинг и метрики

### 5.1 Prometheus + Grafana
#### Метрики AI
- `ai_jobs_processed_total` - всего обработано задач
- `ai_jobs_failed_total` - упавшие задачи
- `ai_generation_duration_seconds` - длительность генерации
- `ai_model_usage_count` - использование по моделям

#### Метрики HTTP
- `http_requests_total` - все запросы
- `http_request_duration_seconds` - время ответа
- `http_requests_in_flight` - активные запросы

#### Метрики S3
- `s3_uploads_total` - загрузок файлов
- `s3_upload_bytes_total` - объём данных

### 5.2 Дашборды
- **Overview** - общая статистика системы
- **AI Performance** - производительность моделей
- **Cost Tracking** - затраты по моделям
- **Queue Status** - состояние очередей

### 5.3 Алерты
- Превышение error rate > 5%
- Длительность генерации > 5 минут
- Очередь задач > 100
- Недостаточно средств на балансе OpenRouter

## 6. Безопасность

### 6.1 Ролевая модель (RBAC)
| Роль | Права |
|------|-------|
| **Admin** | Полный доступ, управление пользователями, настройки системы |
| **Manager** | Создание генераций, управление пресетами, сохранение в CRM |
| **Viewer** | Только просмотр галереи и пресетов |

### 6.2 Шифрование данных
- **AES-256-GCM** для чувствительных данных
- Шифрование токенов Bitrix24
- Шифрование API ключей OpenRouter
- Ключи хранятся в environment variables

### 6.3 Rate Limiting
| Endpoint | Лимит | Окно |
|----------|-------|------|
| `/api/generate` | 10 запросов | 1 минута |
| `/api/presets` | 50 запросов | 1 минута |
| `/api/bitrix/*` | 100 запросов | 1 минута |

### 6.4 Аудит и логирование
- Структурированные логи (pino)
- Логирование всех критических операций
- Ротация логов
- Экспорт в SIEM-системы

### 6.5 CORS и CSP
- Настройка разрешённых источников
- Content Security Policy заголовки
- Helmet.js для защиты заголовков
- HTTPS/TLS обязательный

## 7. Инструменты сравнения

### 7.1 Side-by-Side режим
- Одновременный просмотр двух изображений
- Синхронизированный зум и панорамирование
- Переключение между версиями

### 7.2 Grid режим
- Отображение 4+ изображений сеткой
- Гибкая настройка количества колонок
- Быстрое переключение между режимами

### 7.3 Overlay режим
- Наложение изображений с регулируемой прозрачностью
- Ползунок для плавного перехода
- Выявление различий в деталях

### 7.4 История версий
- Хранение всех версий изображения
- Метаданные: промт, модель, параметры, дата
- Возможность отката к любой версии
- Экспорт истории в PDF/JSON
