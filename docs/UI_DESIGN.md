# UI/UX Design Documentation

## Дизайн-система (untitlet/ui-admin style)

### Основные принципы
- **Чистый минимализм** — много воздуха, четкая иерархия
- **Bitrix24-inspired** — знакомые паттерны для пользователей Битрикс
- **Top Navigation** — без левой колонки, максимум пространства для контента
- **Контекстная помощь** — панель справа по клику на ❓

---

## Компоненты

### 1. Header (Навигация)
```
┌─────────────────────────────────────────────────────────────────┐
│ 🤖 AI Generator           [Создание][Пресеты][Настройки][Каталог]   ❓ 👤 │
│    Bitrix24 Integration                                         │
└─────────────────────────────────────────────────────────────────┘
```

**Особенности:**
- Логотип с градиентом
- 4 вкладки навигации с иконками
- Активная вкладка: синий фон + ring
- Кнопка помощи ❓ справа
- Аватар пользователя

---

### 2. Help Panel (Панель помощи)
```
┌─────────────────────────────┐
│ Помощь                  ✕   │ ← Заголовок + закрыть
│ Создание изображений        │ ← Описание раздела
├─────────────────────────────┤
│ 🔍 Поиск по темам...        │ ← Поиск
├─────────────────────────────┤
│ ▼ Загрузка изображения      │ ← Аккордеон (развернут)
│   Перетащите изображение... │   Содержимое темы
│   Смотрите также: [Пресеты] │   Связанные темы
├─────────────────────────────┤
│ ▶ Написание промта          │ ← Аккордеон (свернут)
├─────────────────────────────┤
│ ▶ Негативный промт          │
└─────────────────────────────┘
```

**Функции:**
- Выезжает справа при клике на ❓
- Авто-выбор раздела по активной вкладке
- Поиск по темам
- Аккордеон для тем
- Связанные темы (теги)

## Стилевые классы (Tailwind)

### Карточки
```css
.ui-card {
  bg-white rounded-xl border border-slate-200 shadow-sm
}
.ui-card-hover:hover {
  shadow-md border-slate-300
}
```

### Кнопки
```css
.ui-btn-primary {
  bg-blue-600 text-white hover:bg-blue-700 shadow-sm
}
.ui-btn-secondary {
  bg-white text-slate-900 border border-slate-200 hover:bg-slate-50
}
.ui-btn-ghost {
  hover:bg-slate-100 text-slate-700
}
```

### Поля ввода
```css
.ui-input {
  h-10 rounded-lg border border-slate-200
  focus:ring-2 focus:ring-blue-500
}
.ui-textarea {
  min-h-[80px] rounded-lg border border-slate-200
}
```

### Бейджи
```css
.ui-badge-success {
  bg-emerald-100 text-emerald-700
}
.ui-badge-warning {
  bg-amber-100 text-amber-700
}
.ui-badge-processing {
  bg-blue-100 text-blue-700 animate-pulse
}
```

## Адаптивность

| Breakpoint | Ширина | Поведение |
|------------|--------|-----------|
| Mobile     | <640px | 1 колонка, скрытые labels |
| Tablet     | 640-1024px | 2 колонки |
| Desktop    | >1024px | 3 колонки, full layout |

## Интерактивность

- **Hover**: легкое изменение фона/тени
- **Focus**: ring-2 с цветом primary
- **Active**: scale-95 для кнопок
- **Transition**: duration-200 ease-in-out
- **Disabled**: opacity-50 pointer-events-none
